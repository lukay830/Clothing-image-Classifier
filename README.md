# Clothing Image Classifier

A CNN-based image classification web application built using TensorFlow and Streamlit.

## Features

- Upload clothing images
- Predict clothing category
- Display prediction confidence
- Display top 3 predictions

## Classes

- Dress
- Hat
- Longsleeve
- Outwear
- Pants
- Shirt
- Shoes
- Shorts
- Skirt
- T-shirt

## Technologies

- Python
- TensorFlow / Keras
- Streamlit
- NumPy
- Pillow
